# 吃啥

一个面向高校生活圈的餐饮决策 MVP，帮助用户在预算、距离、口味、心情和社交场景等条件下，更快决定这一顿吃什么。

**在线体验：** [campus-food-adviser.vercel.app](https://campus-food-adviser.vercel.app/)

## 产品背景

“今天吃什么”是学生群体高频但低价值的决策。相比只按价格、距离筛选，用户往往会用“只有 20 分钟”“刚打完球”“下雨不想出门”“宿舍一起吃”等自然场景表达需求。

「吃啥」尝试把这些场景转化为可操作的标签和推荐条件，通过更短的路径完成餐厅发现与选择。目前以上海五角场高校生活圈为试点范围，覆盖同济大学、复旦大学和上海财经大学三个学校入口。

## 核心功能

- 三类场景标签：功能需求、心情场景、社交时间
- 当前分类内“换一换”，展示更多有效标签
- 按学校切换餐厅供给与推荐结果
- 预算、品类和距离三步决策向导
- 校园餐厅推荐榜与地图圈层展示
- 餐厅详情、收藏和本设备使用记录
- 中英文界面切换与移动端适配

## 当前状态

这是用于验证产品流程的前端 MVP。餐厅名称、评分、访问次数及地图位置为演示数据，不代表真实商家或真实运营结果。后续计划通过用户测试和实地采集逐步替换为真实数据。

## 技术实现

- React 18
- Vite 5
- Tailwind CSS
- React Router
- i18next
- Vercel

收藏、浏览和决策记录目前保存在浏览器本地，无需登录。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```
